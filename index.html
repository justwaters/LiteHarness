Why LiteHarness?

🪶

Tiny footprint

~10 MB binary. No Node, Python, or Rust toolchain. No garbage-collected runtime bloat.

💻

32-bit + 64-bit

Cross-compiles from one machine to any target — x86, ARM, Linux, macOS. Run it anywhere.

⚡

Streaming responses

Tokens print as they arrive from the LLM. No waiting for the full completion before you see output.

🔧

Full tool set

Read, write, edit, grep, glob, ls, run commands, and manage todos — just like Claude Code.

🌐

Any provider

OpenAI-compatible (Ollama, OpenRouter, NVIDIA NIM, generic) and Gemini API support.

⌨️

Slash commands

/help, /exit, /clear, /model, /provider, /system, /tools, /save — all from the REPL.

Built-in Tools

LiteHarness exposes these tools to the model during conversation:

read_file
Read the contents of a file.
write_file
Write or overwrite a file with content.
edit_file
Replace a specific string in a file (str_replace).
ls
List files and directories in a path.
grep
Search file contents with regex.
glob
Find files matching a glob pattern.
run_command
Run a shell command and return output.
todo_write
Manage a todo list during work.

Configuration
# ~/.liteharnessrc
provider=openai
base_url=https://api.openai.com/v1
model=gpt-3.5-turbo
api_key=sk-...
system_prompt=You are a helpful coding assistant.

Installation

1

Download a binary

Get the latest release for your platform from GitHub:

  • Linux 64-bit: liteharness-linux-amd64
  • Linux 32-bit: liteharness-linux-386
  • macOS Intel: liteharness-darwin-amd64
  • macOS Apple Silicon: liteharness-darwin-arm64
2

Make it executable

chmod +x liteharness-linux-amd64
3

Run it

export LITEHARNESS_API_KEY=your-key
./liteharness-linux-amd64

Or build from source:

GOOS=linux GOARCH=amd64 go build -o liteharness .
