A tiny AI coding harness styled after Claude Code. Cross-platform, minimal memory, no runtime dependencies.

Built-in tools

LiteHarness exposes these tools to the model during conversation:

  • read_file Read the contents of a file.
  • write_file Write or overwrite a file with content.
  • edit_file Replace a specific string in a file (str_replace).
  • ls List files and directories in a path.
  • grep Search file contents with regex.
  • glob Find files matching a glob pattern.
  • run_command Run a shell command and return output.
  • todo_write Manage a todo list during work.

model=gpt-3.5-turbo
api_key=sk-...
system_prompt=You are a helpful coding assistant.

Installation

One-line install (detects your OS and architecture automatically):

curl -fsSL https://raw.githubusercontent.com/justwaters/LiteHarness/master/install.sh | bash

Installs liteharness into ~/.local/bin. Make sure that directory is on your PATH.

  • 1

    Download a binary

    Get the latest release for your platform from GitHub:

    • Linux 64-bit: liteharness-linux-amd64
    • Linux 32-bit: liteharness-linux-386
    • macOS Intel: liteharness-darwin-amd64
    • macOS Apple Silicon: liteharness-darwin-arm64
  • 2

    Make it executable

    chmod +x liteharness-linux-amd64
  • 3

    Run it

    export LITEHARNESS_API_KEY=your-key
./liteharness-linux-amd64

    Or build from source:

    GOOS=linux GOARCH=amd64 go build -o liteharness .
